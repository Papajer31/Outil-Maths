# SQL des prochains patchs

Ces fichiers sont pensés pour une base existante.

- `01_add_student_code.sql` : ajoute le code élève.
- `02_catalogue_visibility.sql` : ajoute le masquage/affichage des activités du Catalogue.
- `03_missions.sql` : note de renvoi vers le gros fichier Missions complet.
- `04_adaptation_aventure.sql` : note de renvoi vers la préparation Aventure.

Pour une refonte sans rétrocompatibilité, il est plus simple d’utiliser `../from_scratch/` après backup/reset.

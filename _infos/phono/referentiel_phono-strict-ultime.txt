# ============================================================
# RÉFÉRENTIEL MINIMAL DES PHONÈMES — BANQUE ULTIME
# ============================================================
#
# Principe : ce fichier ne contient que les cibles phonémiques simples
# nécessaires pour analyser les 4 714 mots de la banque.
#
# codes = unités de la banque qui réalisent directement la cible.
# inclus_dans = macros grapho-phonologiques utilisées dans la banque
#               qui contiennent aussi ce phonème, sans constituer elles-mêmes
#               des phonèmes (ex. oi = /w/+/a/, x = /k/+/s/).
#
# IMPORTANT : la banque ne distingue actuellement pas /o/ de /ɔ/,
# ni /ø/ de /œ/. Ces deux paires restent donc fusionnées ici pour
# conserver un référentiel opérationnel fidèle aux données.
# Les séparer strictement exigerait de recoder les mots concernés.
# ============================================================

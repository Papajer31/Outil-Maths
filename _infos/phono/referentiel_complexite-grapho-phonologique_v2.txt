# ============================================================
# RÉFÉRENTIEL DE COMPLEXITÉ GRAPHO-PHONOLOGIQUE — BANQUE ULTIME
# ============================================================
#
# Principe :
# ce fichier attribue un niveau de complexité de 1 à 5 aux codes
# du référentiel grapho-phonologique de la banque.
#
# Le niveau porte sur la réalisation graphique réellement rencontrée
# dans le mot, et non sur le phonème abstrait.
#
# Exemple :
#   j    = niveau 1
#   g_j  = niveau 3
#   ge   = niveau 4
#
# alors que ces trois codes réalisent le même phonème /ʒ/.
#
# RÈGLE DE CALCUL POUR UN MOT :
# complexité_du_mot = niveau maximal parmi tous les codes du mot.
#
# Exemple :
# un mot contenant uniquement des codes de niveaux 1 et 2 est niveau 2.
# un mot contenant un seul code de niveau 5 est niveau 5.
#
# Les niveaux sont conçus pour servir de filtre pédagogique dans
# les exercices adaptatifs :
#
#   1 = très simple
#   2 = simple et fréquent
#   3 = intermédiaire
#   4 = complexe
#   5 = très complexe, rare ou exceptionnel
#
# Les variantes explicites de type code=graphie sont également listées
# lorsqu'elles peuvent apparaître telles quelles dans la banque.
# Elles héritent du niveau de leur code parent.
#
# 149 entrées au total : 143 codes de référence + 6 variantes explicites.
#
# syntaxe : code|niveau
# ============================================================
